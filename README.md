# 🪐 Clustering Universe

**Clustering Universe** is an interactive, space-themed educational application designed to demystify unsupervised machine learning. Built with Streamlit and scikit-learn, it provides a "hands-on" journey through the cosmos of clustering algorithms.

---

## 🌌 Features

- **Interactive Live Demos**: Real-time visualization of how parameters like $K$, $\epsilon$, and $min\_samples$ affect cluster formation.
- **Algorithm Exploration**:
  - **⚙️ K-Means**: Watch centroids converge and visualize Voronoi regions.
  - **🌿 Hierarchical**: Build cosmic family trees with interactive dendrograms.
  - **🌊 DBSCAN**: Explore density-based clustering and noise detection in nebulae.
- **Evaluation Suite**: Compare results using Silhouette Score, Davies-Bouldin Index, and Calinski-Harabasz Index.
- **Real-World Use Cases**: Interactive expanders showing applications in Retail, Healthcare, Cybersecurity, and more.
- **Premium Aesthetics**: A custom-styled UI with "Space Mono" typography, glassmorphism components, and dynamic starfield backgrounds.

## 🚀 Getting Started

### Prerequisites
- Python 3.8+
- pip

### Installation

1. **Clone the repository**:
   ```bash
   git clone <your-repository-url>
   cd CLUSTERING
   ```

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Launch the application**:
   ```bash
   streamlit run app.py
   ```

## 🛰️ Navigation

The app is divided into 7 cosmic modules:
1. **Introduction**: The basics of unsupervised learning.
2. **K-Means**: Centroids, orbits, and the Elbow Method.
3. **Hierarchical**: Family trees and linkage strategies.
4. **DBSCAN**: Density, core points, and noise.
5. **Evaluation**: Measuring the quality of constellations.
6. **Choosing Algorithms**: A decision matrix for data scientists.
7. **Applications**: Real-world impact across industries.
